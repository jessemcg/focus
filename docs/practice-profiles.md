# Practice profiles are retired in Focus

All new Focus research uses the [fixed neutral method](research-method.md), including
previously profile-bound cases. There is no advanced profile option or management UI.
Private profile files and historical saved answers are untouched, not migrated.

RecordPrep still owns preparation profiles. Focus accepts descriptive preparation
provenance without a counterpart profile. Only profile_contract.py and
profile_artifacts.py remain byte-identically vendored for compatibility.
